# 05. 독립 검산

## 언제

- 에이전트가 낸 숫자가 문서나 원고에 들어가기 전.
- 관문 판정의 근거가 되는 값.
- 원고의 모든 숫자(품질 반복의 한 단계).

## 어떻게

1. 검산 에이전트를 새로 띄운다. 앞선 대화를 넘기지 않는다.
2. 주는 것: 규칙 문서(봉인된 것), 원자료 경로, 보고할 숫자의 정확한 목록(이름, 단위, 자릿수).
3. 주지 않는 것: 원래 집계 코드, 원래 값, 총괄의 해석.
4. 검산 에이전트는 자기 코드로 다시 세고 표로 낸다. 코드도 함께 낸다.
5. 총괄이 원래 값과 대조한다. 일치 수와 불일치 수를 적는다. 불일치는 하나씩 원인을 찾는다.

원고를 고친 뒤 고정판과 숫자, 인용, 부등호, 헤지를 비교하는 사실 대조는 `fact-check` 스킬이 맡는다.

양식은 `templates/검산지시문.md`.

## 문헌 정찰의 검산

문헌 정찰도 검산한다. 정찰 에이전트가 "가장 가까운 논문"이라고 낸 것을 다른 에이전트가 본문까지 열어 "같은 문제인가, 부분인가, 인접인가"를 따로 판정한다. 두 판정이 다르면 총괄이 본문을 직접 연다.

## 독립 검토

검산은 숫자를, 검토는 결론을 본다. 큰 문서(주제 검토, 연구 계획)는 초안을 다른 에이전트에게 주고 "자기 코드로 다시 세고, 출처를 다시 열고, 판정을 반박하라"고 시킨다. 검토가 잡은 지적은 큰 지적(결론을 바꾸는 것)과 작은 지적으로 나눠 반영 여부와 함께 문서에 남긴다. 검토가 결론을 뒤집은 기록은 지우지 않는다.

## 기록

```
독립 검산 (날짜)
대상: ... (값 N개)
일치: n / 불일치: m
불일치 원인: ...
검산 코드: 경로
```
