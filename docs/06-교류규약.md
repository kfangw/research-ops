# 06. 교류 규약

claude와 chatgpt(Codex)가 같은 연구 저장소를 번갈아 고칠 때의 규약이다. 두 도구는 서로 대화하지 않고, git 커밋과 `00-교류/`의 파일로만 변경을 주고받는다.

현행 규약은 `scaffold/template/`에 들어 있고, 스캐폴드로 연 프로젝트는 처음부터 이 규약을 갖는다. 프로젝트를 만드는 스킬은 `research-scaffold`, 세션을 시작하고 마치는 스킬은 `research-session`이다.

## 뼈대

| 파일, 폴더 | 무엇 |
|---|---|
| `AGENTS.md` | 도구가 세션 시작 때 읽는 규칙. `CLAUDE.md`는 `@AGENTS.md` 한 줄로 이 파일을 가리킨다 |
| `00-교류/현황.md` | 무엇이 현행이고 누가 맡는지. 단일 기준. 다른 문서와 어긋나면 이 파일이 맞다 |
| `00-교류/log/YYYY-MM-DD-NN-도구.md` | 세션 기록. 세션마다 파일 하나 |
| `00-교류/<보낸 도구>-to-<받는 도구>/` (예: `claude-to-codex/`) | 인계 노트. 보낸 쪽이 쓰고 받는 쪽이 `status`를 바꾼다 |
| `docs/승인기록.md` | 사용자 결정과 세션 판정 |

## 기준은 GitHub main

맥 폴더, Claude 클라우드, Codex 클라우드는 모두 클론이다. 세션은 `git pull --rebase origin main`으로 시작해 `git push origin main`으로 끝난다. 브랜치는 main 하나이고, 며칠 걸리는 실험은 `exp/이름`, 사용자가 자리를 비운 동안의 작업은 `away/<시작>`을 쓴다(`docs/08-사용자가-없는-시간.md`). 같은 산출물을 동시에 고치지 않는 담당 규칙이 충돌을 막는다.

## 세션

시작할 때는 pull 뒤에 현황과 `log/`의 최근 세 파일을 읽고, 자기 앞으로 온 노트(`status: 대기`)를 읽어 `확인`으로 바꾼 다음 `git log --oneline -20`을 본다.

마칠 때는 인계 노트를 쓰고 현황을 갱신한 뒤 `log/`에 세션 파일 하나를 남긴다. 그다음 접두(`[claude]`, `[chatgpt]`)를 붙여 커밋하고 push한다. 커밋의 작성자는 사용자이고 도구는 메시지 끝의 `Co-Authored-By:` 줄로 공동 작성자가 된다. 도구마다 git identity를 따로 두던 구판과 달리, 커밋이 사용자 계정에 잡히고 어느 도구가 함께 만들었는지는 접두와 공동 작성자 줄로 남는다. 스캐폴드가 거는 `code/hooks/commit-msg`가 이 규칙을 검사한다. 거절되면 pull --rebase 뒤 다시 push한다. force push는 하지 않는다. 자세한 절차는 `research-session`에 있다.

## 세션 기록을 세션별 파일로 바꾼 이유

구판(0.8까지 `protocols/구판/exchange/`에 두었고 지금은 git 이력에 있다)은 `LOG.md` 한 파일 맨 위에 줄을 끼워 넣었다. 도구 하나가 로컬 폴더에서만 쓸 때는 문제가 없었지만, 두 도구가 각자의 클라우드 클론에서 같은 파일 머리를 고치면 push마다 거의 매번 충돌한다. 세션마다 새 파일을 쓰면 충돌할 일이 없다. 구판 규약으로 운영 중인 프로젝트를 새 구조로 옮기는 절차는 `research-session`에 있다.

## 충돌 규칙

같은 산출물을 동시에 고치지 않는다. 담당은 현황에만 적는다. 새 판을 올리면 지난 판은 `구판/`으로 내린다. 금지 행위는 사용자 확인 뒤에만 한다. 상대 파일을 지우거나 옮기면 노트로 알린다. git 이력을 고쳐 쓰지 않는다.

## 작업 저장소와 공개 저장소

작업 저장소에는 무엇이든 넣는다. 투고용 artifact는 `code/scripts/export-artifact.sh`로 `code/`만 새 이력으로 뽑아 별도 저장소로 내고, 거기에는 프로젝트 이름, 사용자 이름, AI 흔적을 남기지 않는다.

## 세션 종료 세 줄

세션을 끝낼 때 승인기록이나 현황에 "오늘 대화 세 줄"을 적으면 다음 날 점검이 쉬워진다. 결정이 아니어도 사용자가 걱정한 것, 외부에서 들은 것, 미뤄 둔 것을 적는다.
