# 04. 사전 등록과 봉인

실험이나 측정의 사양과 판정 규칙을 결과 전에 적고 봉인한다. 절차는 `preregister-seal` 스킬에 있다.

## 사전 등록 문서에 들어갈 것

1. 물음. 한 문장.
2. 자료. 무엇을, 어느 기간, 어디서. 자료의 체크섬이 있으면 적는다.
3. 셈. 무엇을 어떻게 세는가. 정의를 글로 적고, 코드가 있으면 코드 경로와 해시.
4. 판정. 어떤 값이면 어떤 결론인가. 문턱 숫자.
5. 반증 조건. 어떤 값이 나오면 가설을 버리는가.
6. 보고 규칙. 결과 방향과 무관하게 보고한다. 원고에 싣지 않기로 하면 승인기록에 남긴다.
7. 열지 않는 자료. 평가용 자료는 규칙 고정 전에 열지 않는다. 탐색용 자료와 평가용 자료를 나눈다.

양식은 `templates/사전등록.md`.

## 봉인

```
python code/scripts/seal.py seal <규칙파일> [--note "한 줄"]
```

규칙 파일의 SHA-256, 봉인 시각(UTC와 지역 시각), 메모를 `<규칙파일>.seal.json`에 쓴다. 결과가 나온 뒤:

```
python code/scripts/seal.py verify <규칙파일>
```

해시가 같으면 "봉인 유지", 다르면 "봉인 뒤 변경"을 출력한다. 변경이 있으면 이탈로 보고 승인기록에 이유를 적는다.

## 규칙을 쓰는 에이전트

규칙 문서를 쓰는 에이전트에게는 결과 파일을 주지 않는다. 탐색 단계의 요약 통계(분포의 꼴, 자료 크기)는 줄 수 있지만 평가 자료의 값은 주지 않는다.

## 탐색과 평가

탐색 자료로 규칙을 만들고, 평가 자료에 한 번만 적용한다. 탐색에서 본 것을 평가 규칙에 넣는 것은 괜찮지만, 평가 결과를 보고 규칙을 고치는 것은 안 된다. 같은 자료를 탐색과 평가에 모두 쓰면 그 사실을 한계에 적는다.
