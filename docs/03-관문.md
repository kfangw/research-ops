# 03. 관문

관문은 "다음 단계로 가도 되는가"를 결과 전에 정한 기준으로 판정하는 장치다. 판정 절차는 `feasibility-gate` 스킬에 있다. 관문에 앞서 `problem-grill`로 문제 정의를 잠그고, G0의 증거는 `literature-scout`로 모은다.

## 관문 목록

| 관문 | 물음 | 통과 기준의 꼴 | 못 넘으면 |
|---|---|---|---|
| G0 신규성 | 같은 문제나 같은 꼴의 결과가 있는가 | 지정 범위(학회, 프리프린트) 전수 대조에서 거리 1 논문 0편. 같은 꼴의 고전 결과는 인용으로 처리할 수 있다 | 접는다, 또는 차이가 분명한 부분으로 좁힌다 |
| G1 실재 | 문제가 현장에 실재하는가 | 공개 자료에서 비율 N% 이상 또는 규모 M 이상 | 측정 논문으로 줄이거나 접는다 |
| G2 단순 대안 | 가장 단순한 대안을 이기는가 | 공정한 대조군(심사자가 고를 법한 강한 기준선)이 실패하는 조건을 실행으로 재현 | 설계를 빼고 측정만 남긴다 |
| G3 자명성 | 주장이 모형의 정의에서 바로 나오는가 | 정의상 참인 부분을 빼고도 결과(크기, 비교, 반례)가 남는다 | 성질로 한 문단만 두고 결과를 다시 찾는다 |
| G4 자료 | 증거를 얻을 자료가 있는가 | 공개되고 검증 가능하다. 직접 만들 자료는 재현 경로와 비용이 정해져 있다 | 범위를 자료가 있는 쪽으로 옮긴다 |
| G5 일정과 요건 | 마감, 투고처, 졸업이나 과제 요건에 맞는가 | 남은 주 수 안에 핵심 결과가 나온다는 어림 | 다른 편에 흡수하거나 뒤로 미룬다 |
| G6 겹침 | 다른 프로젝트와 겹치는가 | 같은 질문, 같은 자료, 같은 선행 연구를 쓰는 편이 없거나 경계가 한 문장으로 정해져 있다 | 경계를 정하거나 한쪽에 흡수한다 |
| G7 닫힘 | 증명과 구현이 닫히는가 | 정리가 서고 구현이 검사를 통과 | 주장을 줄인다 |

G0, G2, G3, G6은 거의 늘 본다. G2와 G3은 G0과 같은 날 함께 본다. G7은 착수 뒤의 중간 관문이고, G5는 투고처를 바꿀 때 따로 다시 본다.

문턱의 숫자(N, M)는 실험 전에 고정한다. "안"으로 적어 두었다가 실행 전에 사용자가 확정하고, 결과를 본 뒤에는 바꾸지 않는다. 판정은 통과, 미통과, 조건부, 유보 가운데 하나로 적는다. 기준을 글자 그대로 적용한 문자 판정과 판정자의 종합 판정이 다르면 둘 다 적고 이유를 쓴다.

## 기록

관문마다 아래를 남긴다. 양식은 `templates/관문.md`.

```
관문 G1 실재 (날짜, 총괄)
물음: ...
기준(고정 날짜, 사용자 확정 여부, 봉인 해시): ...
결과(근거 파일): ...
독립 검산: 대조 n개, 불일치 m개
문자 판정: 통과 / 미통과 / 유보
종합 판정: 통과 / 미통과 / 조건부 / 유보
가능성 어림: 이전 → 지금 (이유)
다음: ...
```

## 접은 주제 목록

관문에서 못 넘은 주제는 접은 주제 목록에 이유, 날짜, 자료의 행방과 함께 둔다. 지우지 않는다. 같은 주제가 다시 올라오면 그 기록부터 읽는다. 여러 편을 함께 진행하면 `research-portfolio`가 접은 주제를 모아 다른 프로젝트에서도 볼 수 있게 한다.

## 가능성 어림

관문 전의 가능성 어림은 낮춰 읽는다. 어림을 고치면 이전 값과 이유를 어림 기록부(`docs/어림기록.md`)에 남긴다. 예: "10-01에 40~50%로 적었다가 관문 뒤 10%로 고침". 이 이력이 있어야 다음 어림을 믿을 수 있다.

## 공통으로 확인할 것

어떤 새 주제든 착수 전에 아래 세 가지를 본다.

1. 선행 연구 재대조(G0). 찾지 못했다는 것은 없다는 것과 다르므로, 검색어와 확인한 학회 목록을 적는다.
2. 가장 단순한 대안과의 비교(G2). 기존 설정 하나, 짧은 시한 하나, 우회 경로 하나로 같은 효과가 나면 논문이 되지 않는다.
3. 공개 자료로 증거를 얻을 수 있는지(G4). 직접 만들어야 하는 자료가 있으면 그 비용을 먼저 적는다.
