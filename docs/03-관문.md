# 03. 관문

관문은 "다음 단계로 가도 되는가"를 결과 전에 정한 기준으로 판정하는 장치다.

## 꼴

| 관문 | 물음 | 통과 기준 | 못 넘으면 |
|---|---|---|---|
| G0 | 같은 문제를 푼 논문이 있는가 | 지정 학회와 프리프린트 전수 대조에서 0편 | 접는다, 또는 차이가 분명한 부분으로 좁힌다 |
| G1 | 문제가 현장에 실재하는가 | 공개 자료에서 비율 N% 이상 또는 금액 M 이상 | 측정 논문으로 줄이거나 접는다 |
| G2 | 가장 단순한 대안을 이기는가 | 대안이 실패하는 조건이 실행으로 재현 | 설계를 빼고 측정만 남긴다 |
| G3 | 증명과 구현이 닫히는가 | 정리가 서고 구현이 검사를 통과 | 주장을 줄인다 |

문턱의 숫자(N, M)는 실험 전에 고정한다. "안"으로 적어 두었다가 실행 전에 확정하고, 결과를 본 뒤에는 바꾸지 않는다.

## 기록

관문마다 아래를 남긴다.

```
관문 G1 (날짜, 총괄)
물음: ...
기준(고정 날짜): ...
결과: ...
판정: 통과 / 미통과 / 조건부
근거 파일: ...
다음: ...
```

## 접은 것 목록

관문에서 못 넘은 주제는 "접은 것" 절에 이유와 날짜와 함께 둔다. 지우지 않는다. 같은 주제가 다시 올라오면 그 기록부터 읽는다.

## 가능성 어림

관문 전의 가능성 어림은 낮춰 읽는다. 어림을 고치면 이전 값과 이유를 남긴다. 예: "10-01에 40~50%로 적었다가 관문 뒤 10%로 고침". 이 이력이 있어야 다음 어림을 믿을 수 있다.

## 세 가지 공통 관문

어떤 새 주제든 착수 전에 세 가지를 본다.

1. 선행 연구 재대조. 찾지 못했다는 것은 없다는 것과 다르므로, 검색어와 확인한 학회 목록을 적는다.
2. 가장 단순한 대안과의 비교. 기존 설정 하나, 짧은 시한 하나, 우회 경로 하나로 같은 효과가 나면 논문이 아니다.
3. 공개 자료로 증거를 얻는가. 직접 만들어야 하는 자료가 있으면 그 비용을 먼저 적는다.
