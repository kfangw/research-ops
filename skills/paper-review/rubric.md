# 모의 심사 기준표 (판 3)

paper-review 스킬이 쓴다. 점수는 같은 판의 기준표끼리만 비교한다. 기준표를 고치면 판 번호를 올리고 아래 변경 줄에 적는다.

- 판 1: 축 일곱, 기준 문장, 일반 저널 판과 학회 판, 투고처 판 만드는 법.
- 판 2: 판 1을 출판 논문에 시험했더니 최상위 학회의 수상 논문이 reject로 나왔다(지나치게 엄격함). 큰 지적을 "치명"과 "고칠 수 있음"으로 나누고 축 상한은 치명에만 걸었다(2절). 학회 판에 수정 조건부 accept를 두고 일반 저널 판의 reject 조건을 치명 지적에 묶었다(3절). A4를 논리 구조, 구성과 가독성, 표현의 세부 진단으로 나눴다(2.1절). 견본 기준선 절을 더했다(5절). 판 1 점수와 판 2 점수는 비교하지 않는다.
- 판 3: 판 2를 출판 논문 셋에 시험했더니 엄격함은 풀렸으나, A4 세부 진단의 "고칠 곳"이 출판 논문에도 9~13개씩 나와 환산 점수가 모두 2가 되었다. 판정을 맞음, 가벼움, 고칠 곳의 셋으로 나누고 점수는 고칠 곳으로만 환산했다(2.1절). 잴 수 있는 항목은 잰 값으로 판정한다. 종합의 할 일 목록은 셋 모두 고칠 곳으로 본 항목부터 둔다(SKILL 5절). 견본 기준선과의 차를 종합에 반드시 적는다(5절). 결정 규칙은 판 2와 같다. 판 2와 판 3의 A4 점수는 비교하지 않는다.

## 1. 축 일곱

| 축 | 묻는 것 |
|---|---|
| A1 기여 | 지식에 무엇을 더하는가. 기존 연구와 구별되는가. 그 차이가 분야에 의미가 있는가 |
| A2 기술적 건전성 | 방법, 증명, 실험 설계, 분석이 맞는가 |
| A3 주장과 증거 | 주장의 크기가 증거에 맞는가. 자료가 결론을 받치기에 충분한가 |
| A4 명료성과 구성 | 처음 읽는 독자가 문제, 기여, 결과를 따라갈 수 있는가. 그림과 표가 본문을 받치는가 |
| A5 위치 짓기와 참고문헌 | 가장 가까운 선행 연구와의 차이가 분명한가. 참고문헌이 적절하고 충분한가 |
| A6 재현과 보고 | 다른 사람이 같은 결과를 얻는 데 필요한 정보(자료, 도구 판, 설정, 반복, 누락)가 있는가 |
| A7 투고처 적합성 | 투고처의 범위와 독자, 분량, 양식에 맞는가 |

축은 학술지 심사 양식이 흔히 묻는 질문(기여, 기술적 건전성, 제시, 참고문헌)과 보안, 시스템 학회의 통상 축(novelty, soundness, presentation)을 나눠 놓은 것이다.

### 1.1 흔히 쓰는 이름과의 대응

| 흔히 쓰는 이름 | 표준 축 |
|---|---|
| Novelty, Originality, 새로움, Significance, 의의 | A1 |
| Technical soundness, Technical quality, 정확성 | A2 |
| Evidence, Evaluation adequacy, 평가 | A3 |
| Clarity, Presentation, 명료성, 표현, 가독성, 발표 점수 | A4 |
| Related work, 관련 연구, 참고문헌 | A5 |
| Reproducibility, Artifact, 재현 | A6 |
| Relevance, Fit, 주제 적합 | A7 |
| Overall, 종합 | 축 점수가 아니라 투고처 판의 결정 규칙으로 낸다 |
| major, 1급, Must | 큰 지적 |
| minor, 2급, Should | 작은 지적 |
| 문장, 형식, typo | 표현 지적 |

## 2. 점수 기준 문장 (1~5)

모든 축에 공통 규칙:
- 큰 지적은 둘로 나눈다. **치명**은 지금의 자료와 방법으로는 고쳐도 결론이 서지 않는 것이다(새 실험이나 새 증명이 있어야 하거나, 방법이 결론을 낼 수 없다). **고칠 수 있음**은 범위 한정, 서술, 추가 분석, 빠진 정보 보충으로 결론이 서는 것이다. 판단이 서지 않으면 고칠 수 있음으로 두고 이유를 적는다.
- 그 축에 치명 지적이 있으면 3점 이하. 고칠 수 있는 큰 지적만 있거나 작은 지적이 셋 이상이면 4점 이하.
- 잘 쓰인 출판 논문도 심사자가 큰 지적을 낸다. 큰 지적이 있다는 것만으로 점수를 깎지 말고, 그 지적이 결론에 얼마나 닿는지로 매긴다.

| 축 | 5 | 4 | 3 | 2 | 1 |
|---|---|---|---|---|---|
| A1 기여 | 가장 가까운 선행 연구와의 차이가 분명하고, 그 차이로 분야의 문제를 새로 풀거나 새로 보게 한다 | 차이가 분명하고 의미가 있으나 범위가 좁다 | 차이는 있으나 작거나, 의미를 원고가 충분히 보이지 못한다 | 차이가 불분명하거나 이미 알려진 결과에 가깝다 | 새로운 것이 없다 |
| A2 건전성 | 방법과 분석에 오류가 없고, 위협과 가정이 명시되며 대안 설명을 배제한다 | 작은 빈틈은 있으나 결론에 영향이 없다 | 결론에 영향을 줄 수 있는 빈틈이 하나 있다 | 빈틈이 여럿이거나 핵심 단계가 틀렸다 | 방법이 결론을 낼 수 없다 |
| A3 주장과 증거 | 모든 주장(초록, 서론, 결론 포함)이 본문 근거와 같은 크기이고, 한계와 범위가 명시된다 | 한두 곳의 주장이 근거보다 조금 넓다 | 핵심 주장 하나가 근거보다 넓거나 근거가 간접적이다 | 여러 주장이 근거를 넘는다 | 결론이 자료에서 나오지 않는다 |
| A4 명료성과 구성 | 처음 읽는 독자가 서론 셋째 문단 안에서 문제와 기여를 알고, 절의 순서와 연결이 자연스럽다. 서론의 약속마다 이행 자리가 있다 | 막히는 곳이 몇 군데 있으나 흐름은 선다 | 구성은 서나 정의 없는 용어, 내부 이름, 과정 서술 같은 장애가 잦다 | 기여나 결과를 찾기 어렵다 | 읽고 따라갈 수 없다 |
| A5 위치 짓기 | 가장 가까운 연구들을 빠짐없이 들고 차이를 하나씩 말한다 | 차이는 분명하나 빠진 연구가 조금 있다 | 가까운 연구 하나 이상이 빠지거나 차이가 뭉뚱그려진다 | 선행 연구 대비가 거의 없다 | 선행 연구를 잘못 전한다 |
| A6 재현과 보고 | 자료, 도구 판, 설정, 반복 수, 누락과 그 처리가 있고 재현 자료가 공개된다 | 재현 자료는 있으나 일부 설정이 빠졌다 | 핵심 설정 일부가 빠져 재현이 어렵다 | 재현에 필요한 정보 대부분이 없다 | 재현할 수 없다 |
| A7 적합성 | 투고처의 범위 한가운데이고 분량과 양식을 지킨다 | 범위 안이나 양식이나 분량에 손볼 곳이 있다 | 범위의 가장자리이거나 독자에게 맞춘 설명이 부족하다 | 범위 밖에 가깝다 | 범위 밖이다 |

### 2.1 A4 세부 진단: 논리 구조, 구성과 가독성, 표현

A4 점수와 별도로 심사자마다 아래 항목을 판정한다. 판정은 넷이다.
- **맞음**: 잘 쓰인 출판 논문과 같거나 낫다.
- **가벼움**: 흠은 있으나 잘 쓰인 출판 논문에도 흔한 정도다. 고치면 좋지만 심사에서 감점되지는 않는다.
- **고칠 곳**: 잘 쓰인 출판 논문보다 눈에 띄게 못하다. 처음 읽는 독자가 막히거나, 심사자가 지적할 정도다.
- **해당 없음**.

판정이 가벼움과 고칠 곳 사이에서 망설여지면 가벼움으로 두고 이유를 적는다. "가벼움"과 "고칠 곳"이면 원고 위치와 힌트를 한 줄로 적는다. 힌트는 무엇을 어느 방향으로 바꿀지와 잘 쓰인 출판 논문이 그 자리를 어떻게 쓰는지이고, 고친 문장은 쓰지 않는다. 원고 안에 그 항목을 잘 한 곳이 있으면 "본보기"로 위치를 적는다. 기준값은 paper-framing, paper-readability, english-academic-style 7절의 출판 논문 견본 범위다.

| 묶음 | 항목 | 묻는 것 |
|---|---|---|
| 논리 구조 | L1 약속과 이행 | 서론의 기여와 연구 질문마다 본문에 이행하는 자리(절, 표, 그림, 정리)가 있는가 |
| | L2 주장과 근거의 거리 | 주장 문장의 근거가 같은 단락이나 바로 옆 표와 그림에 있는가 |
| | L3 절의 연결 | 최상위 절의 첫 단락이 앞 절과의 관계나 이 절이 답할 물음을 말하는가 |
| | L4 단락의 첫 문장 | 첫 문장만 이어 읽어도 논증이 따라오는가. 표만 가리키는 첫 문장이 없는가(모든 단락을 같은 꼴로 맞출 필요는 없다) |
| | L5 주장의 크기 | 초록과 결론의 주장(범위, 일반화, 평가어)이 본문 근거보다 넓지 않은가 |
| | L6 한계의 자리 | 한계를 어디서든 다루고, 같은 한계를 여러 곳에서 되풀이하지 않는가 |
| 구성과 가독성 | G1 서론의 속도 | 셋째 문단 안에서 이 논문이 하는 일을 말하는가. 분야 일반론이 한 문단을 넘지 않는가 |
| | G2 초록과 결론의 꼴 | 초록이 한 문단 120~250단어, 숫자 네 개 이하인가. 결론이 450단어 이하이고 새 숫자가 없는가 |
| | G3 정의와 이름 | 정의 전에 쓰는 용어, 정의 없는 내부 이름과 코드명, 한 대상의 여러 이름이 없는가 |
| | G4 기호와 숫자 | 본문의 기호와 숫자가 읽기를 막지 않는가. 표의 숫자를 본문이 다시 나열하지 않는가 |
| | G5 그림과 표 | 첫 쪽이나 둘째 쪽에 결과를 요약하는 그림이나 표가 있는가. 그림과 표가 주장을 직접 받치는가 |
| 표현 | E1 AI 흔적과 과장 | 강조 공식, not X but Y, 무대 세우기, 평가어("superior"), 금지 어휘가 없는가 |
| | E2 헤지와 한정 | 헤지가 확실성에 맞는가(너무 없거나 겹치지 않는가). 한 문장에 단서가 겹쳐 달리지 않는가 |
| | E3 문장의 결 | 문장 길이가 고르지 않게 섞였는가. 되읽어야 하는 문장, 괄호가 겹친 문장이 드문가 |
| | E4 과정 이력 | 판 이력, 이전 판과의 비교, 내부 검토 기록 같은 과정 서술이 본문에 없는가 |

잴 수 있는 항목은 잰 값으로 판정한다. G2(초록 단어 수와 숫자 수, 결론 단어 수), E2(1천 단어당 헤지, 문장당 한정), E3(문장 길이 평균과 표준편차, 괄호가 두 쌍 이상인 문장의 비율)는 english-academic-style 7절과 paper-framing의 범위를 쓴다. 견본의 25~75 백분위 안이면 맞음, 10~90 백분위 안이면 가벼움, 그 밖이면 고칠 곳이다. 프로젝트에 측정 스크립트가 있으면 그 값을 쓰고, 없으면 심사자가 어림한 값과 어림했다는 사실을 적는다.

A4 점수는 "고칠 곳"의 개수로만 환산한다. 하나 이하이면 5, 둘에서 셋이면 4, 넷에서 여섯이면 3, 일곱 이상이면 2를 기준으로 하고, 기준 문장과 어긋나면 이유를 적는다. "가벼움"은 점수에 넣지 않는다.

확신도(1~5): 5는 이 주제의 전문가로서 원고를 자세히 읽었다, 3은 주제는 알지만 일부를 확인하지 못했다, 1은 추측이다.

## 3. 기본 투고처 판

결정 규칙은 축 중앙값과 합의된 큰 지적에 적용한다.

### 3.1 일반 저널 판

- accept: 합의된 큰 지적 0, 모든 축 4 이상
- minor revision: 합의된 큰 지적 0, 모든 축 3 이상
- major revision: 합의된 치명 지적 0이고, 합의된 큰 지적이 모두 고칠 수 있음. A1, A2, A3 가운데 2점인 축이 있어도 그 원인이 고칠 수 있는 지적이면 여기에 든다
- reject: 합의된 치명 지적이 있거나, A1, A2, A3 가운데 하나가 1

### 3.2 학회 판

- 통상 축(novelty, soundness, presentation)에 A1, A2, A4가 대응한다. 결정은 accept와 reject 둘이다(학회에 shepherding이나 major revision이 있으면 투고처 판에 적는다).
- accept: 합의된 큰 지적 0, A1과 A2가 4 이상, 나머지 축 3 이상
- 수정 조건부 accept(shepherding): 합의된 치명 지적 0, 합의된 큰 지적이 모두 고칠 수 있음, A1 4 이상, A2 3 이상, 나머지 축 3 이상. 학회에 shepherding이 없으면 "고쳐서 다음 회 재투고 권함"으로 읽는다
- reject: 그 밖

## 4. 투고처 판 만드는 법

투고처가 공개한 심사 지침이 있으면 그 투고처의 판을 만들어 프로젝트에 둔다(`docs/설정.md`의 심사 절이 가리키게 한다).

1. 공식 심사 질문을 원문 그대로 옮기고 출처 주소와 확인한 날짜를 적는다. 찾지 못한 항목은 "미확인"으로 적는다.
2. 질문마다 대응하는 축(1절)을 적는다.
3. 투고처의 결정 이름(accept, minor, major, reject, 재투고 허용 등)을 그대로 쓰고, 결정마다 축 점수와 합의된 큰 지적으로 된 규칙을 적는다.
4. 투고처가 무겁게 보는 축을 적는다(예: 독창성 문턱이 낮고 건전성을 무겁게 보는 학술지면 A2와 A3을 무겁게, A1은 3점이면 충분).
5. 투고처가 major revision을 한 번만 허용하는 등의 절차 제약이 있으면 적는다. 그런 투고처는 첫 투고에서 합의된 큰 지적이 없어야 한다.

## 5. 견본 기준선

축 점수는 절대값보다 같은 기준표 판으로 잰 잘 쓰인 출판 논문과 나란히 볼 때 뜻이 있다. 모델 심사자는 출판 논문에도 큰 지적을 낸다.

1. 프로젝트마다 투고처나 같은 분야의 잘 쓰인 출판 논문 둘 이상을 같은 기준표 판, 같은 투고처 판, 같은 심사자 구성으로 심사해 둔다. 이것이 견본 기준선이다. 기준표 판이 바뀌면 다시 잰다.
2. 견본에는 심사자가 알아보기 어려운 논문(유명하지 않은 출판본)을 섞는다. 알아본 논문은 점수가 오를 수 있다.
3. 원고를 심사하면 종합(SKILL 5절)에 원고의 축 중앙값과 견본 기준선, 그 차를 반드시 나란히 적는다. 원고가 축마다 기준선과 같거나 높으면 "출판 견본 수준"으로 읽는다. 기준선이 없으면 "기준선 없음"이라고 적고, 점수 합만으로 원고의 수준을 말하지 않는다. 이 기준표는 최상위 학회 수준과 평균 저널 수준은 가르지만 그 사이는 잘 가르지 못한다(판 2 시험).
5. 견본 본문은 출판본(publisher version)으로 만든다. 저자 판(arXiv 등)은 출판본과 다를 수 있다. 심사자에게 넘기기 전에 제목, 저자, 소속, 감사의 글, 저자 기여 진술, 그리고 쪽 머리말과 각주의 출판 표기(저널 이름, 채택 표기, DOI, 학회 이름)를 찾아 지운다.
4. 기준선 값은 공개 판에 싣지 않고 프로젝트 기록에 둔다.

## 6. 이 판의 한계

- 기준 문장은 흔한 심사 양식의 질문을 풀어 쓴 것이고, 투고처가 실제로 쓰는 점수표와 같다는 보장은 없다.
- 결정 규칙은 이 체계의 약속이다. 실제 편집 결정과 맞는지는 실제 심사평이 오면 대조한다(SKILL 6절).
- 판 2의 결정 규칙은 판 1 시험 결과를 보고 고쳤고, 다른 출판 논문 셋으로 다시 시험해 견본이 reject가 되지 않음을 확인했다. 다만 그 셋은 저자 판이었다.
- 판 3의 A4 환산은 판 2 시험 결과를 보고 고쳤다. 다른 출판본으로 다시 시험하기 전에는 확인된 규칙이 아니다.
- A4 진단의 기준값은 보안 분야 저널과 학회 논문 견본에서 왔다. 다른 분야에서는 그 분야 견본으로 다시 잰다.
