# 스킬

각 폴더의 `SKILL.md`가 전부다. 설치하지 않고 필요한 `SKILL.md`를 도구에게 읽혀도 되고, Claude Code, Codex, claude.ai에 설치하는 법은 저장소 루트의 `AGENTS.md` 4절과 `code/scripts/install-skills.sh`에 있다. 모든 스킬은 research-session의 공통 규칙을 따르고, 용어는 한 이름으로 통일했다.

| 단계 | 스킬 | 하는 일 |
|---|---|---|
| 운영 기반 | research-scaffold | 프로젝트 폴더를 만들거나 기존 폴더에 구조를 입힌다 |
| 운영 기반 | research-session | 세션 시작과 마침, 인계, 모든 스킬의 공통 규칙 |
| 여러 편 | research-portfolio | 연구 지도, 편 사이 경계, 공용 문헌 대장, 투고처와 요건 점수, 결정 전파, 일일 점검 |
| 착수 | problem-grill | 질문으로 문제 정의를 확정하고 잠근다. 틀 변경을 센다 |
| 착수 | literature-scout | 선행 연구 정찰. 같은 수학 꼴의 고전 이론까지 찾는다 |
| 착수 | feasibility-gate | 관문 G0~G7을 결과 전에 정한 기준으로 판정한다 |
| 실행 | preregister-seal | 실험 사양과 판정 규칙을 봉인하고 이탈과 누설, 수집 비용을 기록한다 |
| 실행 | research-batch | 할일목록 새 판, 역할 배정, 연속 실행, 수시 보고 |
| 원고 | paper-framing | 초록, 서론, 결론의 구조와 주장 목록 |
| 원고 | paper-quality-loop | 심사, 분류, 수정, 문체의 바퀴를 기준에 닿을 때까지 |
| 원고 | paper-readability | 내용을 고정한 원고를 처음 읽는 독자에게 맞춘다 |
| 원고 | paper-condense | 쪽 수 상한에 맞추고 군더더기를 자른다 |
| 심사 뒤 | rebuttal | 실제 심사평에 대한 대응표와 답신 |
| 공용 | fact-check | 고친 원고와 고정판의 사실 대조, 원자료 검산, 인용 검증 |
| 공용 | korean-academic-style | 국문 학술 문체 규범 |
| 공용 | english-academic-style | 영문 학술 문체 규범 |

흐름은 problem-grill, literature-scout, feasibility-gate로 착수를 판정하고, preregister-seal과 research-batch로 실행하고, paper-framing에서 paper-quality-loop로 원고를 다듬는 순서다. 같은 큰 지적이 두 바퀴 남으면 feasibility-gate나 problem-grill로 돌아간다.

문체 스킬 둘은 한 사람의 규범이므로 자기 규범으로 바꿔 쓰는 것이 맞다. 경로와 이름은 자리표시자로 두었다.
