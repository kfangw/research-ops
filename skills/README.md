# 스킬

Claude Code의 `.claude/skills/` 또는 claude.ai 프로젝트의 스킬로 올려 쓴다. 각 폴더의 `SKILL.md`가 전부다.

| 스킬 | 하는 일 |
|---|---|
| research-scaffold | 새 연구 프로젝트를 저장소 하나와 교류 규약으로 열기, 기존 폴더에 입히기, 세션 절차. 틀 전체를 본문에 담음 |
| ai-exchange-protocol | 구판 교류 규약(LOG 한 파일)의 설치와 세션 절차. 스캐폴드 이전 프로젝트용 |
| batch-run-report | 남은 일을 배치로 나눠 연달아 실행하고 수시 보고 |
| paper-todo-update | 할일목록 새 판본과 역할 매핑, 기록 문서 맞춤 |
| paper-quality-loop | 원고를 심사·분류·실행·문체의 바퀴로 돌리고 기준에 닿으면 멈춤 |
| paper-framing | 초록·서론·결론의 구조 원칙과 주장·증거 점검 |
| paper-condense | 쪽 수 상한에 맞추기 |
| paper-readability | 처음 읽는 독자를 위한 가독성 |
| korean-academic-style | 국문 학술 문체 규범 |
| english-academic-style | 영문 학술 문체 규범 |

개인 경로는 `<프로젝트 루트>`, `<프로젝트 경로>` 같은 자리표시자로 바꿨다. 문체 스킬 둘은 한 사람의 문체 규범이므로 자기 규범으로 바꿔 쓰는 것이 맞다.
