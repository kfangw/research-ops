# 진행판 양식

모든 스킬의 보고에 쓰는 세 틀. 규범은 `research-session` 8절, 이유와 예시는 `docs/09-진행-보이기.md`.

상태어: `[예정]` `[진행]` `[대기]` `[막힘]` `[멈춤]` `[완료]` `[건너뜀]`
막대: 12칸, 항목 수로 센다. `[######------] 6/12  50%`

## 시작 안내

단계가 셋 이상이거나 5분 넘게 걸릴 일은 시작하기 전에.

```
== 시작 | <프로젝트> | <할 일> | HH:MM ==
지금   : <세션을 시작할 때만. 현행 판, 결정 대기, 대리 판정 대기, 검토서>
목표   : <끝나면 무엇이 생기나>
순서   : 1 <단계> --> 2 <단계> --> 3 <단계>
         (2a || 2b 함께)
어림   : <전체> (<단계별>)
사용자 : <사용자가 할 일과 그 시점, 없으면 없음>
멈춤   : <멈춤 조건, 없으면 없음>
```

## 진행판

상태가 바뀔 때. 에이전트나 배경 작업이 돌고 있으면 에이전트 표를 넣는다.

```
== 진행 | <프로젝트> | <할 일> | HH:MM (시작 HH:MM, 경과 n분, 남은 어림 n분) ==
전체   [------------] 0/n  0%
단계   1 <이름> [예정]  2 <이름> [예정]

에이전트    역할        맡은 일              상태     시작   마지막 신호  진척
<이름>      <역할>      <한 줄>              [진행]   HH:MM  HH:MM        <n/m>
<이름>      <역할>      <한 줄>              [대기]   HH:MM  HH:MM        응답 없음 n분, HH:MM까지 없으면 다시 띄움

최근   HH:MM <일어난 일 한 줄>
대기   <무엇을>, 어림 n분, HH:MM에 다시 알림
결정   <없으면 없음>
```

## 마침 보고

```
== 끝 | <프로젝트> | <할 일> | HH:MM (걸린 시간 n분, 어림 n분) ==
결과   : <핵심 한두 줄, 숫자>
확인   : <독립 검산이나 대조 결과 / 미검산 / 해당 없음(이유)>
바뀐 것: <파일 n개, 아래 링크>
남은 것: <결정 n건, 할 일 n건, 하지 않은 것, push하지 않은 커밋>
다음   : <제안 하나>
```

## 멈춘 것처럼 보이지 않게

- 사용자가 보는 곳에 5분 넘게 아무 표시도 없게 두지 않는다.
- 2분 넘게 걸릴 일 직전에 무엇을 기다리는지, 어림, 다음 알림 시각을 보인다.
- 어림의 1.5배를 넘기면 알리고 새 어림을 적는다.
- 응답 없는 에이전트는 `[진행]`이 아니다. 어림을 넘기고 5분이 더 지나면 `[대기]`(다시 띄울 시각), 다시 띄워도 없으면 `[막힘]`.
- 호출 중 화면이 잡히는 도구는 직전 안내에 끝날 어림 시각을 적고, 끝나면 바로 진행판을 보인다.
- 사용자가 자리를 비운 동안에는 검토서 진행 칸의 마지막 신호를 30분 안의 간격으로 고친다. 30분 넘게 지난 `[진행]`은 멈춘 것으로 본다.
- 시작 안내와 마침 보고의 줄 이름에만 콜론을 붙인다. 확인할 것이 없으면 확인 줄에 `해당 없음(이유)`.
