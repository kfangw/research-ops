# 측정 규칙 v1

봉인: `측정규칙-v1.md.seal.json`. 봉인 뒤 바꾸려면 사용자가 정하고 승인기록에 남긴다. 이탈은 `이탈기록.md`.

1. 대상: 보안 공지가 있는 패치 릴리스와 그 패키지에 직접 또는 간접으로 의존하는 패키지(깊이 1~4).
2. 반영 시점: 하위 패키지가 패치된 판 이상을 허용하는 첫 릴리스의 시각.
3. 반영 시간: 반영 시점에서 패치 릴리스 시각을 뺀 값(일). 90일 안에 반영하지 않으면 중도 절단으로 둔다.
4. 측정: 깊이별 중앙값과 부트스트랩 95% 구간(반복 2,000). 예외는 깊이 3 이상인데 깊이 1의 중앙값보다 빠른 경우.
5. 판정: 깊이 2와 3의 중앙값 차이가 2일보다 크면 "깊이 효과 있음", 아니면 "깊이 효과 없음".
6. 표본: 패치 300건. 수집은 하루 API 5,000회 안에서 한다.
