# demo-study (견본)

운영 체계를 처음 쓰는 사람이 "채워진 프로젝트가 어떻게 생겼나"를 보도록 만든 가상 프로젝트다. 연구 주제, 문헌, 숫자는 모두 지어낸 것이고 사실이 아니다. 스캐폴드(`SCAFFOLD_TOOLS=claude`)로 만든 뒤 일주일 동안의 기록을 채웠다. 이야기 속 날짜는 지어낸 것이고, 봉인 기록(`.seal.json`)의 시각은 견본을 실제로 봉인한 시각이다. 이 폴더에는 git 이력이 없으므로 커밋 해시와 `away/` 브랜치는 이야기 속의 것이고, 맡김에서 받은 산출 파일(`code/collect.py`, `data/processed/patches.csv`, `results/summary/depth.csv`)도 생략했다.

가상 주제: 공개 패키지 저장소에서 보안 패치가 나온 뒤 그 패키지에 의존하는 패키지들이 패치를 반영하기까지 걸리는 시간.

## 읽는 순서

```
 1 문제 정의        2 선행 연구 정찰      3 관문 판정           4 사전 등록과 봉인
 problem-grill --> literature-scout --> feasibility-gate --> preregister-seal
 docs/문제정의-v2   docs/정찰/          docs/관문/            docs/사전등록/
        |                                                         |
        v                                                         v
 manuscript/주장목록.md                                   5 배치 계획
 (paper-framing)                                          research-batch
                                                          docs/할일목록.md
                                                                  |
                                                                  v
                          7 돌아와서 검토  <--  6 자리를 비운 동안 맡김
                          docs/맡김/*-검토서     docs/맡김/*-지시서 (away/ 브랜치)
                                  |
                                  v
                          00-교류/현황.md, docs/승인기록.md, 00-교류/log/
```

| 순서 | 파일 | 무엇을 보면 되나 |
|---|---|---|
| 1 | `docs/문제정의-v2.md` | 한 문장 문제, 반증 조건, 잠금 해시 |
| 2 | `docs/정찰/2026-10-02-정찰.md` | 검색어 기록, 거리 판정, 찾지 못함의 기록 |
| 3 | `docs/관문/2026-10-03-G0.md`, `2026-10-03-G2.md` | 결과 전에 정한 기준, 문자 판정과 종합 판정 |
| 4 | `docs/사전등록/측정규칙-v1.md` | 판정 규칙과 봉인 기록(`.seal.json`) |
| 5 | `docs/할일목록.md` | 배치, 통과 조건, 사용자 결정 |
| 6 | `docs/맡김/2026-10-05-2230-지시서.md` | 바꾸지 않을 것, 갈림길의 사전 결정, 멈춤 선 |
| 7 | `docs/맡김/2026-10-05-2230-검토서.md` | 결정 대기, 확인 상태, 사용자 표시 |
| 8 | `docs/승인기록.md`, `00-교류/현황.md`, `00-교류/log/` | 결정과 대리 판정, 현행 판, 세션 기록 |
| 9 | `manuscript/주장목록.md` | 주장, 증거, 감당 여부 |

진행판과 시작 안내, 마침 보고의 예는 `00-교류/log/`의 세션 기록 끝에 붙여 두었다.

AI 도구 규칙은 `AGENTS.md`.
