# 이 프로젝트에서 일하는 AI 도구를 위한 규칙

이 폴더는 {{사용자}}의 {{프로젝트}}이다.
{{도구A}}와 {{도구B}}가 같은 폴더에서 번갈아 일하며, 서로의 변경은 `00-교류/`로 전달한다.

## 세션을 시작하면

1. `00-교류/현황.md`를 읽는다. 어느 {{산출물}}의 어느 판이 현행이고 누가 맡고 있는지는 여기가 기준이다.
2. `00-교류/LOG.md` 위쪽 열 줄과, 자기 앞으로 온 인계 노트(`status: 대기`)를 읽고 `status`를 `확인`으로 바꾼다.
3. `git log --oneline -20`으로 상대의 커밋을 본다.
4. 프로젝트 지도가 필요하면 `INDEX.md`.

## 세션을 마치면

인계 노트를 쓰고, `현황.md`와 `LOG.md`를 갱신하고, `[{{도구A}}]` 또는 `[{{도구B}}]` 접두를 붙여 커밋한다.
형식과 자세한 규칙은 `00-교류/README.md`.

## 지켜야 할 것

- `현황.md`의 담당 칸에 적힌 쪽만 그 {{산출물}}을 고친다.
- 새 판을 만들면 지난 판은 같은 폴더의 `구판/`으로 내린다. 지우지 않는다.
- {{금지행위}}는 사용자 확인 후에만 한다. 그 직전 단계까지만 준비한다.
- 상대가 만든 파일을 지우거나 옮길 때는 인계 노트에 적는다.
- {{코드저장소}}에 프로젝트 이름이나 AI 흔적을 남기지 않는다.
- git 이력을 고쳐 쓰지 않는다. `.gitignore`가 뺀 큰 파일을 강제로 넣지 않는다.
- 국문 문서는 담백한 학술 문어로 쓴다. 산문 속 기호(·, —, →), "핵심은 ~다"류 강조 공식, 번역투 피동을 쓰지 않는다. 영어 용어는 영문 그대로 둔다.
