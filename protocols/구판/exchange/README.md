# 교류 규약 파일 세트

두 AI 도구가 같은 폴더를 번갈아 쓸 때 프로젝트 루트에 복사하는 파일들. 자리표시자 `{{...}}`를 채워 쓴다. 설치와 세션 절차는 `../../skills/ai-exchange-protocol/SKILL.md`.

| 파일 | 어디에 두나 |
|---|---|
| `AGENTS.md` | 프로젝트 루트. `CLAUDE.md`도 같은 내용으로 |
| `00-교류/README.md` | 규칙 본문 |
| `00-교류/현황.md` | 단일 진실 |
| `00-교류/LOG.md` | 시간순 대장 |
| `00-교류/인계노트-양식.md` | 노트 양식 |
| `gitignore` | `.gitignore`에 덧붙임 |

| 자리표시자 | 뜻 |
|---|---|
| `{{프로젝트}}` | 폴더가 무엇인지 한 줄 |
| `{{사용자}}` | 두 도구를 쓰는 사람 |
| `{{도구A}}`, `{{도구B}}` | 커밋 접두와 폴더명에 쓸 소문자 이름 |
| `{{산출물}}` | 담당을 나누는 단위(원고, 모듈 등) |
| `{{코드저장소}}` | 문서 폴더 밖 별도 저장소 |
| `{{금지행위}}` | 사용자 확인 없이 하면 안 되는 일 |
