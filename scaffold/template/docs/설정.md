## 커밋 작성자

커밋은 사용자와 도구가 함께 만든다. 작성자는 언제나 사용자이고, 도구는 작성자가 되지 않는다. 도구가 만든 커밋은 접두(`[도구]`)를 붙이고 메시지 끝에 빈 줄 하나를 둔 뒤 아래 공동 작성자 줄을 붙인다. 사용자가 손으로 만든 커밋과 자동 저장 커밋에는 접두와 공동 작성자 줄을 붙이지 않는다.

- 이름: {{사용자}}
- 메일: {{사용자 메일}}

| 도구 | 공동 작성자 줄 |
|---|---|
| {{도구1}} | `Co-Authored-By: {{도구1 공동작성}}` |
| {{도구2}} | `Co-Authored-By: {{도구2 공동작성}}` |<!--두도구-->

- 메일은 사용자의 GitHub 계정에 등록된 주소를 쓴다. 그래야 커밋이 사용자 계정에 잡히고 공동 작성자도 함께 표시된다.
- 도구가 스스로 붙이는 공동 작성자 줄이 있으면 그 줄을 쓴다(예: 모델 이름이 들어간 Claude의 줄). 도구의 주소를 모르면 이름만 적는다.
- 클론마다 `git config user.name`과 `git config user.email`을 위 값으로 두고 `git config core.hooksPath code/hooks`를 한 번 실행한다. 도구의 작업 공간은 기본 작성자가 도구로 되어 있는 경우가 많으므로 세션을 시작할 때 확인한다.
- `code/hooks/commit-msg`가 작성자가 도구이거나 메일이 위와 다르면, 그리고 접두가 붙은 커밋에 공동 작성자 줄이 없으면 커밋을 막는다. 메일 칸이 비어 있으면 메일은 대조하지 않는다.
