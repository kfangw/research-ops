# 승인기록

사용자가 내린 결정과 판정. 도구의 권고안과 구별해 적는다.

| 날짜 | 결정 | 근거 | 영향 |
|---|---|---|---|
| {{오늘}} | 저장소 하나로 문서와 코드를 함께 관리 | 결과와 코드 판을 커밋 하나로 잇기 위해 | 투고용 artifact는 code/만 따로 뽑음 |

## 대리 판정

총괄이 사용자 대신 정한 것. 사용자가 확인하면 확인 칸을 채운다. 뒤집으면 그 사실과 날짜를 적는다.

| 번호 | 시각 | 무엇을 정했나 | 이유 | 출처(세션, 검토서) | 사용자 확인 |
|---|---|---|---|---|---|
