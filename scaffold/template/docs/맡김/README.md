# 맡김

사용자가 자리를 비운 동안(밤, 회의, 주말) 에이전트에게 맡긴 작업의 지시서와 검토서를 둔다. 절차는 research-batch 스킬 8절, 원칙은 운영 체계 저장소의 `docs/08-사용자가-없는-시간.md`.

| 파일 | 무엇 |
|---|---|
| `<시작>-지시서.md` | 떠나기 전에 쓰고 사용자가 승인한 지시서. 승인 칸이 비어 있으면 실행하지 않는다 |
| `<시작>-검토서.md` | 맡긴 동안의 결과. 돌아와서 항목마다 받음, 돌려보냄, 버림을 표시한다 |
| `지표.md` | 검토할 때마다 한 줄. 끝낸 항목, 받은 항목, 확인 불일치, 실제 검토 시간, 검토 대기 |

`<시작>`은 지시서를 쓴 시각(`YYYY-MM-DD-HHMM`). 지시서는 main에 두고, 맡긴 작업과 검토서는 `away/<시작>` 브랜치에만 커밋한다. 검토 뒤 받은 항목과 검토서를 main으로 가져온다.
